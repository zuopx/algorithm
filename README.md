# algorithm

算法的本质是一个解决问题的系统化步骤或过程。它是通过一系列明确定义的操作、规则和逻辑来达到某个特定目标或解决特定问题的工具。
-   确定性（可预测）
-   抽象性（能通用）
-   有限性（可完成）
-   复杂度（可衡量）

如何描述一个算法？
-   What: A precise specification of the problem that the algorithm solves.
-   How: A precise description of the algorithm itself.
-   Why: A proof that the algorithm solves the problem it is supposed to solve.
-   How fast: An analysis of the running time of the algorithm.

算法在程序中的地位，类似数学在科学中的地位，是根源、是至高绝学。
做数学题，重要的是做对；做算法题，不仅要做对，还要做得快、省。
做数学题，多用演绎法，利用定律、公式，去拓展已知。（当然归纳也很重要）
做算法题，重点在优化，先用最朴素的方法得到答案，然后再利用各种手段去优化。这些优化手段，才是算法的核心。
优化手段，第一是数据结构，数据结构的魔力在于通过巧妙地安排数据，使得维护和利用数据变得更加高效。
优化手段，第二是算法本身，这就包括各种算法模板、算法思想，例如双指针、动态规划等。
